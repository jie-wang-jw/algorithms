# 复杂度速查 / Complexity Quick Reference

## 常见复杂度顺序 / Common Growth Rates

当输入规模 n 足够大时，以下常见增长率从低到高排列。这里比较的是渐近增长速度，不代表每个具体输入上的实际运行时间。

For sufficiently large input size n, the following common growth rates are ordered from slowest to fastest growth. This compares asymptotic growth, not actual running time for every input.

```text
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
```

| 复杂度 / Complexity | 名称 / Name | 常见例子 / Example |
|---|---|---|
| O(1) | 常数 / Constant | 通过下标访问数组 / Array access by index |
| O(log n) | 对数 / Logarithmic | 二分查找 / Binary search |
| O(n) | 线性 / Linear | 遍历数组；指针总移动次数为 O(n) 的双指针算法 / Array traversal; two-pointer algorithms with O(n) total pointer movements |
| O(n log n) | 线性对数 / Linearithmic | 归并排序、堆排序 / Merge sort, heap sort |
| O(n²) | 平方 / Quadratic | 两层各遍历 n 次、循环体为常数时间的循环 / Two nested loops of n iterations each with a constant-time body |
| O(n³) | 立方 / Cubic | 三层各遍历 n 次、循环体为常数时间的循环 / Three nested loops of n iterations each with a constant-time body |
| O(2ⁿ) | 指数 / Exponential | n 个元素的全部子集数量 / Number of subsets of n elements |
| O(n!) | 阶乘 / Factorial | n 个不同元素的全部排列数量 / Number of permutations of n distinct elements |

## 注意事项 / Important Notes

- 子集、排列的数量不等于生成并保存所有结果的完整时间成本。常见回溯实现若逐个复制结果，全部子集需要 O(n × 2ⁿ) 时间，全部排列需要 O(n × n!) 时间。
  The number of subsets or permutations is not the full cost of generating and storing all results. Typical backtracking implementations that copy each result take O(n × 2ⁿ) time for all subsets and O(n × n!) time for all permutations.
- 不能只看循环嵌套层数，要计算总操作次数。例如滑动窗口的左右指针各自最多移动 n 次，即使存在嵌套循环，时间仍可为 O(n)。
  Count total operations rather than just nesting levels. In a sliding window, each boundary may move at most n times, so nested loops can still take O(n) time.
- 大 O 忽略常数因子和低阶项，例如 O(2n) 简化为 O(n)，O(n² + n) 简化为 O(n²)。
  Big O omits constant factors and lower-order terms: O(2n) simplifies to O(n), and O(n² + n) simplifies to O(n²).
- 对数的底数为固定且大于 1 的常数时，不影响大 O 分类，通常统一写作 O(log n)。
  Any fixed logarithm base greater than 1 gives the same Big O class, usually written as O(log n).
